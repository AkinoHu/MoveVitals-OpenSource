# Security policy

MoveVitals handles health data and OAuth tokens, so we take security reports seriously.

**Please do not open public issues for vulnerabilities.** Email **hello@movevitals.com** with:

- a description of the issue and its impact,
- steps to reproduce or a proof of concept,
- the affected version or commit.

We aim to acknowledge reports within 3 working days and will keep you informed while we fix the issue. Please give us reasonable time to release a fix before disclosing publicly.

## Scope

- The hosted service at movevitals.com
- This repository's code (self-hosted deployments included)

Out of scope: vulnerabilities in third-party platforms (WHOOP, Strava, etc.) — report those to the vendor.
